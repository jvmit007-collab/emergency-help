# Emergency Help & Important Contacts — CEP Project

## GitHub Pages
This version is static and can be hosted for free using GitHub Pages.

### Features
- Emergency contacts
- One-click call buttons
- Basic first-aid guide
- Emergency request form
- Mobile responsive design
- No server/database required

### Important
The request form uses browser `localStorage`, so it does not send requests to an administrator. It is a demonstration feature. For a real emergency, call the appropriate emergency service directly.

## Publish
1. Create a GitHub repository.
2. Upload `index.html` and the `assets` folder.
3. Open repository Settings → Pages.
4. Select `Deploy from a branch`.
5. Select `main` and `/ (root)`.
6. Save.
7. GitHub will provide your `https://USERNAME.github.io/REPOSITORY/` address.
